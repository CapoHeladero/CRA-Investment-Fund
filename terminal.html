Start here. This terminal does five jobs: surface opportunities, track your book, value individual names, size new entries safely, and learn from your own signal history. Below is what every section does and the daily/weekly workflow that ties them together.
Step 1 — Set up your Finnhub API key
Required for ANY scanner, deep-dive, or live data. Free, takes 2 minutes.
  1. Go to finnhub.io/register and create a free account
  2. Verify your email, log in, copy your API key from the dashboard
  3. In this terminal, go to Settings (sidebar) and paste it
  4. Status badge in top-right should turn green: API connected

Free tier: 60 API calls/minute. Plenty for personal use. Your key stays in your browser only — never sent anywhere except Finnhub.

Daily workflow (5 minutes)
  1. Open Daily Brief — see book status, last scan results, today's actions
  2. Run Live Scanners if data is stale (>24h old) — takes ~3 minutes total for all four
  3. Check Opportunities Book for any name where the why-now thesis still applies
  4. Log any signals you saw (X posts, news, insider filings) in Signal Log — these get price-stamped automatically and feed the Backtest later
  5. Review Open Book for any position approaching its stop or target
Weekly workflow (30 minutes)
  1. Run Signal Backtest — see which signal sources have been right vs wrong for you. Trust the ones that win, ignore the ones that lose.
  2. Update Watchlist — add names from scanners; remove names whose thesis broke
  3. Check Sector Strength — confirm regime hasn't changed (defensive vs risk-on rotation)
  4. Macro Regime checklist — tick boxes if conditions changed. Risk-off score >5 = reduce gross exposure.
  5. Position sizing review — anything outsized vs original sizing? Trim back.

Politician trades & hedge fund 13Fs — honest limitations

There is no free API for politician trades or hedge fund 13F filings. The workarounds:

  • Politician trades → Bookmark capitoltrades.com/trades and check daily. Filter by trader. Note: 30-45 day legal disclosure lag, so you're always seeing month-old trades.
  • Hedge fund 13F filings → Bookmark dataroma.com (free) or whalewisdom.com (free tier). Note: filings are quarterly with 45-day reporting lag. Longs only, no shorts.
  • Insider trades (Form 4) → The Insider Scanner + Live Scanner already pull these from Finnhub, in near-real-time (1-2 day lag). This is the highest-signal free indicator.
  • Paid options if you want auto-tracking: Quiver Quant ($10-50/mo) for politician trades, WhaleWisdom Pro for 13Fs. Honestly, for most retail use cases, the manual workflow is fine — you're not trying to front-run hedge funds anyway.

Investment mandate
The rules of CRA Investment Fund. The actual edge.
  1. Size every position before entry. Risk per trade ≤ 1-2% of book. Never feel out a size.
  2. Define stop and invalidation before clicking buy. Write it in the thesis box.
  3. If the 5-year thesis cannot be stated in 2 sentences, it is a trade not an investment. Use tighter stops.
  4. Never average down on losers. Add to winners that remain attractively priced.
  5. Avoid names first heard on social media this week.
  6. Maintain 10-20% cash. It is a call option on bad days.
  7. Read the 10-K, not the headline. Balance sheets are signal; news is noise.
  8. If the thesis changes, the position changes. Do not fall in love.
  9. Track every trade with the reason. Review monthly. Most edge comes from removing worst behaviours, not finding better ideas.
  10. The retail edge over funds is time horizon and no LP pressure. Do not waste it by overtrading.
